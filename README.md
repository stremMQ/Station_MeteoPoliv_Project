# MeteoPoliv
✅Здесь находится бот предназначенный для информации о метеостанции и взаимодействию с ней:

  ⚒️бот умеет получать информацию через wifi с датчиков метеостанции и отображать их в телеграмм по кнопке:
  
    информация такая как: влажность почвы, влажность воздуха, температура воздуха и световой индекс(ночь или день).
    
  📃В боте есть вся информация о метеостанции, как она разрабатывалась, кем разрабатывалась, что в ней есть, что она умеет и из чего состоит. Также есть инструкция для
  
самостоятельной сборки, но бот не лежит на каком либо хосте, так что он не работает, для просмотра можно запустить самому. В будущем, возможно некое развитие(не точно).

🌷Также здесь находится код, который вшит в метеостанцию и скрипт для передачи информации с метеостанции в базу данных.

💻код станции написан на языке - с++.

🛠️Станция спроектирована на базе ардуино нано.

📄Скрипт написан на языке - python.
